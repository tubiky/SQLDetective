# SQL 탐정 — 하늘미술관 도난 사건

SQL로 단서를 찾아 범인을 밝히는 수업용 웹 추리 게임입니다.
브라우저 안에서 실제 SQLite(sql.js)가 실행되며, 설치나 서버 DB가 필요 없습니다.

## 구성: 3차시 × 미션 3개 + 범인 지목

| 차시 | 미션 | 배우는 개념 |
|---|---|---|
| 1차시 | 1 사건 현장의 눈 · 2 관련자 명단 · 3 범행 시각의 전시실 | `SELECT *`, 열 고르기, `WHERE` |
| 2차시 | 4 비상구로 나간 사람들 · 5 범행 이후에 나간 사람 · 6 기념품샵 영수증 | `WHERE`, `AND`·비교 연산자, `ORDER BY` |
| 3차시 | 7 번호 대신 이름으로 · 8 검은 모자의 주인 · 9 결정적 증거 → 범인 지목 | `JOIN`, `JOIN`+`WHERE`, 테이블 3개 `JOIN` |

## 자유 연습 (방문 기록 602건, 12문제)

본편과 별개로 언제든 풀 수 있는 SELECT·WHERE 연습입니다. 본편 범인과 관계없는 이야기라 스포일러가 없습니다.
데이터는 고정 시드로 생성되어 모든 학생에게 똑같습니다 (`js/practice.js`).

| 문제 | 개념 |
|---|---|
| 1 기록 훑어보기 | 열 고르기 |
| 2 부산에서 온 손님 | `WHERE =` |
| 3 70세 이상 어르신 | `>=` |
| 4 서울 밖에서 온 사람 | `<>`, `!=` |
| 5 체험관의 어린 손님 | `AND` |
| 6 대구 또는 울산 | `OR` |
| 7 충청권 방문객 | `IN` |
| 8 9월 한 달 | `BETWEEN` |
| 9 기념품샵의 큰손 학생 | `AND` + 숫자 비교 |
| 10 인천에서 온 김씨 | `LIKE` |
| 11 가장 오래 머문 사람들 | `WHERE` + `ORDER BY DESC` |
| 12 분실물의 주인 | 조건 4개 종합 (602건 중 1명 찾기) |

## 실행 방법

`index.html`을 더블클릭하면 **동작하지 않습니다** (브라우저 보안 때문에 WASM 파일을 못 읽음). 웹 주소로 열어야 합니다.

- 내 컴퓨터에서 확인: 이 폴더에서 `python3 -m http.server 8765` 실행 후 http://localhost:8765
- 학생 배포: GitHub Pages 등 정적 호스팅에 폴더째 올리면 됩니다.

## 수업 팁

- 주소 끝에 `?all=1`을 붙이면 모든 미션이 열립니다 (교사 시연용).
- 진행 상황은 학생 브라우저(localStorage)에 저장됩니다. 상단 **처음부터** 버튼으로 초기화.
- 학생 쿼리는 `SELECT`/`WITH`만 실행되므로 데이터가 망가지지 않습니다.

## 파일 구조

- `js/case1.js` — 사건 스토리, 테이블 데이터, 미션·힌트·정답 (새 사건은 이 파일을 복사해 만듭니다)
- `js/engine.js` — 정답 판정, 한국어 오류 설명
- `js/game.js` — 화면과 진행 상태
- `vendor/` — sql.js 1.17.0 (MIT)
