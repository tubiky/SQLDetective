# SQL 탐정 — 하늘미술관 도난 사건

SQL로 단서를 찾아 범인을 밝히는 수업용 웹 추리 게임입니다.
브라우저 안에서 실제 SQLite(sql.js)가 실행되며, 설치나 서버 DB가 필요 없습니다.

## 1장 구성 (8개 미션 + 범인 지목)

| 미션 | 배우는 개념 |
|---|---|
| 1 사건 현장의 눈 | `SELECT * FROM` |
| 2 관련자 명단 | 원하는 열만 고르기 |
| 3 범행 시각의 전시실 | `WHERE` |
| 4 비상구로 나간 사람들 | `WHERE` 연습 |
| 5 범행 이후에 나간 사람 | `AND`, 비교 연산자 |
| 6 기념품샵 영수증 | `ORDER BY` |
| 7 번호 대신 이름으로 | `JOIN` |
| 8 검은 모자의 주인 | `JOIN` + `WHERE` |
| 범인 지목 | 단서 종합 |

## 실행 방법

`index.html`을 더블클릭하면 **동작하지 않습니다** (브라우저 보안 때문에 WASM 파일을 못 읽음). 웹 주소로 열어야 합니다.

- 내 컴퓨터에서 확인: 이 폴더에서 `python3 -m http.server 8765` 실행 후 http://localhost:8765
- 학생 배포: GitHub Pages 등 정적 호스팅에 폴더째 올리면 됩니다.

## 수업 팁

- 주소 끝에 `?all=1`을 붙이면 모든 미션이 열립니다 (교사 시연용).
- 진행 상황은 학생 브라우저(localStorage)에 저장됩니다. 상단 **처음부터** 버튼으로 초기화.
- 학생 쿼리는 `SELECT`/`WITH`만 실행되므로 데이터가 망가지지 않습니다.

## 파일 구조

- `js/case1.js` — 사건 스토리, 테이블 데이터, 미션·힌트·정답 (새 사건은 이 파일을 복사해 만듭니다)
- `js/engine.js` — 정답 판정, 한국어 오류 설명
- `js/game.js` — 화면과 진행 상태
- `vendor/` — sql.js 1.17.0 (MIT)
